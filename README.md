# Повідомлення клієнту — генератор (без ІІ, безкоштовно)

Статична сторінка: менеджер заповнює форму після дзвінка → отримує готовий текст для
клієнта з актуальними цінами → «Скопіювати» або «Надіслати в Telegram / Viber / WhatsApp».
Сервер і API не потрібні, працює на безкоштовному Vercel.

## Що редагувати
Усе в **data.js**:
- `branch` — адреса і телефон філії;
- `topics` — «Що вивчатимуть»: 3–6 пунктів для кожної програми (поки порожньо — менеджер вписує вручну у формі);
- `products` — програми МКА, ПКО, університет, коледж і ціни (з CRM, Харків, 03.11.2026). Оновлюй при зміні прайсу.

Після зміни — завантаж файл на GitHub, сайт оновиться сам, посилання не зміниться.

## Викласти на Vercel (один з варіантів)

**A. Через GitHub (зручно оновлювати):**
1. Створи репозиторій на github.com і завантаж туди ці файли (Add file → Upload files).
2. На vercel.com → Add New → Project → Import цього репозиторію → Deploy (налаштування не чіпати).
3. Отримаєш посилання `https://<назва>.vercel.app` — роздай менеджерам.
   Кожна зміна data.js на GitHub автоматично оновлює сайт.

**B. З комп'ютера через термінал:**
```bash
npx vercel --prod
```
(у папці з цими файлами; перший раз попросить увійти у Vercel).

## Примітки
- Сторінка відкривається будь-кому, хто має посилання (у пошуковиках не індексується).
  Тож не додавай у data.js нічого секретного.
- Безкоштовний тариф Vercel (Hobby) за правилами призначений для некомерційного використання.
  Для робочого інструменту компанії формально потрібен Pro, або можна безкоштовно
  викласти ці ж файли на GitHub Pages, Netlify чи Cloudflare Pages — вони теж підходять.
